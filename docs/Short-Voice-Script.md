# Short Voice Script — IT Competency × PG-BOT

## เวอร์ชันประมาณ 60–90 วินาที

เราใช้คอมพิวเตอร์ทำงานกันทุกวัน แต่ “ใช้เป็น” ไม่ได้แปลว่า “ดูแลเป็น”

IT Competency ขั้นพื้นฐานจึงไม่ใช่การเป็นช่างคอม แต่คือ **รู้ ทำได้ และตัดสินใจเป็น** ว่าอะไรควรทำเอง อะไรควรหยุด และเมื่อใดควรขอความช่วยเหลือ

ความปลอดภัยขององค์กรก็เช่นกัน มันไม่ได้เริ่มที่ Firewall อย่างเดียว แต่เริ่มจากผู้ใช้แต่ละคนที่รับผิดชอบเครื่องมือของตัวเอง และให้ความร่วมมือกับ IT Policy

Pain ของเราไม่ใช่ไม่รู้ แต่คือ **รู้แล้วไม่ได้ทำอย่างสม่ำเสมอ**

ดังนั้น งานที่ต้องใช้วิจารณญาณ เช่น Password การถอน Software หรือการ Update เราต้องตัดสินใจเอง

แต่งานซ้ำที่กติกาชัด ความเสี่ยงต่ำ และตรวจผลได้ เราให้ Automation ช่วยได้

[เว้นจังหวะ]

บลิ๊งงงค์! นี่คือ **PG-BOT — Port Guard Bot**

บอทตัวเล็กที่ทำงานเล็ก ๆ ให้ชัดเจน: Scanning, Cleaning, Verifying แล้วเก็บผลล่าสุดไว้ตรวจสอบ

เป้าหมายไม่ใช่ให้เครื่องทำทุกอย่างแทนคน แต่คือ **ใช้เป็น ดูแลเป็น ป้องกันเป็น**

เพราะเครื่องมือที่ดี ไม่ได้ทำให้คนหยุดคิด — แต่มันคืนเวลาให้เราไปคิดในเรื่องที่สำคัญกว่า
