# NBOO Prompt — IT Competency × PG-BOT Infographic

สร้างอินโฟกราฟิกภาษาไทย 1 หน้า แนว Functional Minimalism สำหรับสรุปงาน “IT Competency × PG-BOT — Port Guard Bot” ใช้สำหรับบุคลากรหน่วยงานภาครัฐและส่งต่อฝ่าย IT

## แกนกลาง
**Policy → Competency → Action**

สื่อความหมายว่า การปฏิบัติตามนโยบาย IT ที่ดีไม่ใช่เพียงทำ checklist ให้ครบ แต่ต้องเข้าใจวัตถุประสงค์ ประเมินความเสี่ยง เลือกวิธีที่เหมาะสม และตรวจสอบผลได้

## เนื้อหาหลัก
1. **IT Competency** = รู้ → ทำได้ → ตัดสินใจเป็น
2. **Security starts with us** = ความปลอดภัยเริ่มจากผู้ใช้ที่รับผิดชอบเครื่องมือของตน และให้ความร่วมมือกับ IT Policy
3. **Pain point** = ปัญหาไม่ใช่ “ไม่รู้” แต่คือ “รู้แล้วไม่ได้ทำอย่างสม่ำเสมอ”
4. **วิธีคิด** = 5ส + Lean + PDCA + ดูสถานการณ์ → ตัดสินใจ → ลงมือ → ตรวจผล
5. **Human vs Automation**
   - คน: Password, การเลือกถอน Software, การตัดสินใจ Update, การประเมินความเสี่ยง
   - Automation: งานซ้ำ กติกาชัด ความเสี่ยงต่ำ ตรวจผลได้
6. **PG-BOT — Port Guard Bot**
   - Scanning → Cleaning → Verifying → DONE
   - ทำความสะอาด User Temp
   - Verify หลังทำงาน
   - เก็บ Receipt ล่าสุด 1 ไฟล์
   - ไม่ขอ Admin / ไม่แตะ Personal files / ไม่ปิด Windows Update, Defender, Firewall / ไม่ถอนโปรแกรม / ไม่ส่งข้อมูลออก
7. **Takeaway**
   **USE → CARE → PROTECT**
   ใช้เป็น • ดูแลเป็น • ป้องกันเป็น

## ประโยคปิด
**“เครื่องมือที่ดีไม่ได้ทำให้คนหยุดคิด แต่คืนเวลาให้คนไปคิดในเรื่องที่สำคัญกว่า”**

## Visual direction
- 16:9 หรือแนวตั้ง A4 ที่อ่านบนมือถือได้
- Dark background, clean, high contrast
- โทนเทคโนโลยีเรียบ สุภาพ ไม่ไซไฟเกินจริง
- ใช้ไอคอนน้อยและมีหน้าที่
- เน้นเส้นทาง Policy → Competency → Action → PG-BOT
- PG-BOT ใช้ terminal motif สีเขียวบนดำเป็น visual accent
- ภาษาไทยต้องถูกต้อง อ่านง่าย ไม่ใส่ข้อความแน่น
- ไม่มีภาพคนแบบ stock photo
- ไม่สร้างข้อมูล ตัวเลข สถิติ หรือ claim เพิ่มจากข้อความนี้
